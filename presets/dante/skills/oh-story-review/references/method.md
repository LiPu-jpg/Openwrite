# 商业审稿方法

## 问题分级

1. 阻断：违背已确认设定、人物状态或时间线；关键因果缺失；章节任务未完成；文本无法进入后续 workflow。
2. 严重：人物为情节突然降智；主角失去已承诺代理权；视角失控；冲突没有结算；关键信息无来源。
3. 一般：节奏拖沓；对话同声；解释重复；情绪铺垫不足；钩子与正文脱节。
4. 润色：句式、用词、标点和局部可读性，不影响上层结构。

同一根因造成多个局部症状时合并为一条主发现，并列受影响位置，避免用数量夸大问题。

## 检查维度

- 事实：称谓、时间、位置、伤势、能力、关系和世界规则能否与真源及前文对齐。
- 因果：事件是否由角色目标、阻力和选择推动，结果是否改变后续条件。
- 契约：本章承诺是否兑现或合理延迟，收益和认可是否结算给应得角色。
- 节奏：铺垫、升级、爆发、余波是否匹配目标情绪，重复段落是否带来变化。
- 信息：读者应知条件是否充分，悬念是否公平，解释是否过早或过晚。
- 表达：视角、对话声音、动作可视性和段落节奏是否服务场景。

## 报告格式

先给总体判断与前三项优先问题，再列严重度统计和逐条发现。每条包含 `位置 / 严重度 / 证据 / 影响 / 最小修复`。最后列修订顺序、无需修改的有效部分、证据不足项和作者待决问题。

需要改写示例时只选择能证明方案的少量段落，提供“原文 / 建议稿 / 理由”。除非用户明确要求，不输出全文重写。
