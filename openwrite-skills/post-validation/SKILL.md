# 后置验证系统

零 LLM 成本的确定性规则检测。reviewer-prose 的合规底线；也用于写章后的快速自检。

## 严重性分级

- `error` — 必须修复（禁止句式等）
- `warning` — 建议修复（AI 味信号）

## 基础规则（error/warning）

| 类别 | 级别 | 规则 |
|---|---|---|
| 禁止句式 | error | "不是…而是…" 强制转折；破折号 ——；省略号 ··· 或 。。 |
| 元叙事标记 | warning | "到这里算是""读者可能""作者想说" |
| 报告术语 | error | 核心动机/信息边界/叙事支撑/弧线转折（策划案术语） |
| 高疲劳词 | warning | 突然/瞬间/旋即/骤然 ≤1 次/章 |
| 转折词密度 | warning | >1 次/3000 字告警 |

## AI 味深度检测（warning，八类）

1. **情节模板化** — 老梗堆叠（退婚/废材逆袭/跳崖得宝）、无真正代价感；改法：加入亲历细节、让冲突基于心理必然
2. **语言太标准** — 语法完美、句式平均、零口语；改法：角色语言习惯、停顿省略、让人物有口音
3. **情绪说出来而非呈现** — "他很悲伤"式标签；改法：动作/身体感受/环境细节（"他把脸埋进手掌里"替代"他很难过"）
4. **缺乏真实细节** — 空泛形容；改法：亲历者才知道的感官细节
5. **陈词滥调与套路比喻** — 心如刀绞/笼罩/眸光/一道/仿佛；改法：个人化比喻或不用比喻
6. **用词句法高度重复** — 同动作 >2 次/章、同表情词 >3 次/章；改法：不同角色不同紧张表现
7. **上下文记忆差/人物前后不一** — 设定被遗忘、行为为剧情服务；改法：核对人物卡与铺垫
8. **节奏感薄弱** — 场景收尾突兀、线性无起伏；改法：关键处留白、段落长短造节奏

## 输出格式

```text
章节质量检测报告 - ch_005
❌ 错误 (必须修复): 1. 禁止句式 2. 报告术语
⚠️ AI味警告: 3. 情绪直白 3处 4. 疲劳词'突然'×4
💡 改进建议: <逐条>
```

## 修复优先级

P0 禁止句式/报告术语（简单替换）→ P1 情绪直白/陈词滥调（改写）→ P2 真实细节（需体验）→ P3 节奏/模板化（整体调整）。

## 时机

写完章后立即检查、提交前终检、感觉"哪里不对"时。
