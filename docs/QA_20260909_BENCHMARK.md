# 章节与大纲模型测试验收（2026-09-09）

## 已实现

- 章节支持推荐下一章、真实计划章节选择和精确 ID；历史事实不可重建的目标明确禁用。
- 大纲支持接续现有大纲或指定起始章，按包含起点的章号范围设计 1–20 章。
- 服务端提供任务能力、范围限制、就绪原因和 DAG；前端使用同一配置，并保留历史运行配置。
- 大纲调用生产 Architect，验证结构和编号，再进行适用范围内的独立评审。
- DAG 阶段记录实际状态、依赖、文件证据和校验值；失败候选跳过评审，已消耗用量保留。
- 多模型候选与评审使用独立产物；章节生产评审也分离工作区，避免覆盖之前的证据。
- 窄屏使用单列任务卡与主要字段；后台失败原因在结果刷新后仍可见。

- `npm run check` 完整通过：27 个组件测试文件、258 项组件测试，以及构建、维护、预设、工具 smoke、epoch、契约校验。
