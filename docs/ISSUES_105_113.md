# 升级恢复与宿主兼容修复（0.2.26）

- #105：0.2 宿主的新会话使用稳定 ID `openwrite`。为历史 `openwrite-0-2-1` 至
  `openwrite-0-2-27`、当前版本及现存版本目录注册兼容定义；已有同 ID 自定义定义优先。
  会话日志与缓存不改写。0.1 所需的版本目录在宿主退出后保留，避免下次恢复悬空引用。
  历史兼容项会出现在宿主预设列表中，这是当前 registry 无 alias API 的限制。
  0.2.27 补充 0.2.26/27 的永久别名，并用发布门禁要求新版本身份进入永久列表，
  避免迁移会话但未复制旧预设目录后再次失效。
- #106 / #107 / #108 / #110 / #112 / #113：根包、bridge、panel、DoG 的精确兼容声明、
  peer 和 lock 元数据同步加入 `0.2.1-rc.3`，保留旧宿主构建基线；发布矩阵加入该版本。
- #111：不支持的平台返回 `RUNTIME_PLATFORM_UNSUPPORTED`（503），包含平台与下一步；
  工具与 Web 代理保留此错误码。外部 Studio 支持可选实例凭据，详见 [安装指南](INSTALL.md#external-studio)。

验证：预设生命周期测试覆盖两宿主、旧身份解析、未来版本稳定 ID、自定义定义和原日志不变。
DSH `0.2.1-rc.3` 隔离 Web 浏览器验收通过：版本闸门、客户端激活、预设选择、作品导航、
工作台三页签、实际渲染、DoG 快照与其他插件共存；模型调用 0。
未在 Windows Electron 或 Android 真机复测；完整发布状态与制品验收以 [GitHub Release](https://github.com/LiPu-jpg/Openwrite/releases/tag/v0.2.26) 和 [发布验收](RELEASE_ACCEPTANCE.md) 为准。
